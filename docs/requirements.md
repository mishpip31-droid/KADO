# KADO — требования и план развития

## Главное назначение

Все скидочные и бонусные карты на одном телефоне. Открыть нужную карту на кассе за одно-два касания. Интерфейс — **веер карт**, словно физический кардхолдер: карты вложены в углублённые слоты, при выборе выдвигаются, свайпы переключают карты.

## Обязательно для версии 0.1

1. Сканирование штрихкода или QR-кода камерой.
2. Импорт кода с фото и скриншота из галереи.
3. Ручное добавление номера, названия и типа штрихкода.
4. Оформление карты: название, цвет, значок; возможность редактировать или удалить.
5. Показ кода крупно, на отдельном экране, с временным повышением яркости.
6. Быстрый поиск, избранное и недавно использованные карты.
7. Полная работа с сохранёнными статическими кодами без интернета.
8. Экспорт и импорт резервных копий без удаления существующих карт.

## Дизайн

Лаконичный, современный Material 3. Светлая и тёмная темы. Плавные, ощутимые анимации веера: новая карта как бы вставляется в держатель, выбранная выдвигается, код открывается отдельным экраном.

## Возможности будущих версий (не включены в 0.1)

- Виджеты на экран Android и кнопка в быстрых настройках.
- Локальная биометрическая блокировка.
- Зашифрованный экспорт и восстановление.
- Реальные изображения и логотипы магазинов.
- Срок действия купонов, промокоды, уведомления.
- Необязательные подсказки по геолокации с разрешения пользователя.
- Интеграции с программами лояльности для балансов, когда есть официальное API.

## Безопасность и качество

Никаких обязательных аккаунтов, облачной синхронизации и рекламы. Базу карт хранить локально и не терять при обычном обновлении приложения. Данные пользователя сохранять при миграциях. Каждое изменение: Graphify → актуальный GitHub → тесты → результат. Без повышения versionCode до проверки текущего значения. Релизная цифровая подпись отдельно от debug-подписи.
