# KADO — скидочные карты в одном веере

Android-приложение для хранения скидочных, бонусных карт и карт лояльности. **Версия 0.1.0** (первая тестовая сборка).

## Возможности

- Веер карт с плавным выдвижением выбранной карты и переключением свайпами.
- Добавление сканированием камерой, с фото или скриншота, ручным вводом номера.
- Показ QR-кодов и распространённых штрихкодов на кассе; временное увеличение яркости.
- Поиск, избранное, недавно использованные карты, редактирование и удаление.
- Локальное хранение SQLite без интернета, рекламы и регистрации.
- Резервная копия JSON, импорт и экспорт карт.
- Светлая и тёмная темы.

## Установка и сборка

Готовый отладочный APK: **Actions → Android debug APK → последний успешный запуск → Artifacts**.
Исходники собираются через GitHub Actions из ветки `main`, а также в Android Studio (JDK 17, Android SDK 35, Gradle 8.9) командой `gradle :app:testDebugUnitTest :app:assembleDebug`.

Параметры приложения: `com.kado.app`, `versionCode=1`, `versionName=0.1.0`, `minSdk=26`.
В GitHub нет секретного ключа релизной подписи; debug APK подписывается автоматически отладочным ключом.

## Ограничения

- Приложение не клонирует защищённые NFC-карты и одноразовые динамические QR-коды.
- На данный момент цвета и значки карт настраиваются, фирменные логотипы магазинов автоматически не подгружаются.
- JSON-резервные копии пока не зашифрованы — храните их безопасно.
- Протестировано автоматической сборкой и unit-тестами; камера, кассовые сканеры и UI на реальном телефоне ещё требуют проверки.
